This file is inert text, not an installed job. Create/edit a single native cron only after owner authorization; use CLI help for version-specific arguments. Choose an explicit timezone and schedule. The reviewed deployment used daily 04:00, not a universal recommendation.

Load media-evidence-library; read its references/retention.md and the active profile's media-library/policy.json in full. Scope is only that exact private library. In report-only, inspect and report without deletion. In delete-expired, require the documented fixture qualification and explicit owner consent, then apply exact verified evidence/cache-only deletion. At most 100 records, 100 files and 50 MiB; skip pinned/active/queued, fresh nested, unknown/invalid, symlink/traversal and unsafe states. Preserve permanent summaries, user dates, sources, task history and all unrelated paths. Recheck before each item, verify afterward and update only cleanup availability metadata. Write actual UTC, exact outcomes, skip reasons, truncation and errors to cleanup-report.md. No recursion/globs, custom code, forwarded media, model/dependency installation or new jobs. On ambiguity skip and report. Native model-driven scheduling is not an outage-proof deletion SLA.
