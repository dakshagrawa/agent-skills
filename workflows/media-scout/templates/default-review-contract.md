# Default review and learning contract

Run in a separate worker session under the configured reviewer profile; use its own authorized context and safe relevant current capability metadata. This is not injection into an existing Desktop chat or permission to read unrelated private profile memories.

## Required result
- Answer the owner's actual purpose: understand/learn, retain reference, assess an idea, research, relate to a project or optionally consider skills/actions. Informational media is not a skill proposal by default.
- Separate creator claims, audiovisual observations, independently verified facts and unknowns. Cite sources/timecodes; preserve sampled-visual limits and ambiguous identifiers.
- Default owns relevance and genuine-gap reasoning. Verify current setup facts when necessary rather than assuming old memory is current.
- Return an attributed learning note with media/packet/source identity, topic/entities, takeaways, confidence, caveats and related context when useful. Persist through native task completion metadata/attachments; intake saves concise retained knowledge and result references in the canonical record.
- Knowledge is searchable but not automatically injected into every chat. There is no blanket memory ingestion. Existing memory rules apply; sharing media does not establish the owner's beliefs or practices. Procedures belong in relevant skills, not global user facts.
- Recommend skills/actions only when justified. Prefer existing/native/official coverage; give reasons, effort, costs, permissions/risks and verification. No action or new skill is a valid outcome. Third-party sources need specific admission and any owner-required exception.
- Any consequential action needs separate approval. This task is REVIEW / PRIVATE KNOWLEDGE CAPTURE ONLY: do not install/create/enable skills, edit code/config, purchase, publish, contact people or start services. Draft an exact versioned proposal only if justified. Default/orchestrator executes and validates only as a later specifically authorized action.
- Complete the actual assigned task with the report/learning note and optional proposal. Never wait for interactive Discord clarify in a headless worker. Preserve same-task retries and exact source return routing; do not claim delivery solely from a configured subscription.
